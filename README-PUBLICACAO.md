# Publicação no GitHub Pages

1. Envie **todo o conteúdo desta pasta** para a raiz do repositório.
2. Mantenha o arquivo principal com o nome `index.html`.
3. No GitHub, acesse **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação.

Não apague os arquivos com nomes longos ao lado do `index.html`: eles são as imagens, fontes e scripts usados pelo site.
